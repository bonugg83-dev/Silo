# 마이픽 전자도서 교정 도우미 (크롬 확장 프로그램)

실로암시각장애인복지관 **마이픽 전자도서 제작** 편집 화면에서, 왼쪽 원본 이미지를 Claude가 직접 보고 오른쪽 OCR 텍스트를 「전자도서제작안내서」 규칙에 맞게 다시 작성해 주는 도우미입니다.

- 원본 이미지가 기준이고, OCR 텍스트는 비교용으로만 씁니다.
- 유니코드 부호(줄표 ―, 산괄호 〈 〉, 부등호 ＜ ＞, 빼기 −, 가운뎃점 ·, 한글 따옴표, ㎝ 등), 빈 줄, 괄호 짝, 띄어쓰기는 프로그램이 한 번 더 검사하고 고칩니다.
- 시각자료, 주석, 애매한 제목 단계, 쪽 번호처럼 사람이 봐야 하는 것은 “확인할 것”에 표시합니다.
- **“제출하기”(최종 제출)는 절대 누르지 않습니다.** 모든 쪽을 확인한 뒤 직접 눌러 주세요.

## 설치 (처음 한 번)

1. 이 저장소를 내려받습니다. GitHub 페이지에서 **Code → Download ZIP** 을 누르고 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 폴더 안의 **`extension`** 폴더를 선택합니다.
5. 크롬 툴바의 퍼즐 모양 아이콘을 누르고 “마이픽 전자도서 교정 도우미” 옆 핀을 눌러 고정합니다.

코드를 새로 내려받았을 때는 `chrome://extensions` 에서 이 확장 프로그램의 새로고침(↻) 버튼을 누르면 됩니다.

## API 키 넣기 / 지우기

1. [console.anthropic.com](https://console.anthropic.com) 에서 API 키를 발급받고 크레딧을 충전합니다.
2. 툴바의 도우미 아이콘을 누르면 오른쪽에 사이드 패널이 열립니다. **설정** 탭의 **키 추가**에 이름(예: “A사용자 키”)과 키를 넣고 **키 추가**를 누릅니다.
3. 키는 여러 개 저장할 수 있습니다. 목록에는 이름과 `sk-ant-…끝 4자리`만 보이고, 왼쪽 동그라미로 사용할 키를 고릅니다. 이름 칸을 고치면 이름이 바뀝니다.
4. 키는 이 컴퓨터의 크롬에만 저장되고 Anthropic API로만 보내집니다. 다 쓴 뒤나 공용 컴퓨터라면 키 옆 **삭제**를 누르세요.

## 사용법

1. 마이픽에서 평소처럼 편집 화면(팝업 창)을 엽니다.
2. **원래 크롬 창**의 툴바에서 도우미 아이콘을 눌러 사이드 패널을 엽니다. (편집 화면은 팝업 창이라 그 창에는 패널이 열리지 않지만, 패널이 열려 있는 편집 화면을 알아서 찾아 작업합니다.)
3. **이 쪽 교정하기**를 누르면 30초~2분 뒤 결과가 나옵니다.
   - **확인할 것**: 빨간 항목은 꼭 확인해야 하는 것, 노란 항목은 참고용 경고입니다.
   - **작성 결과**: 확인할 곳이 글 안에 빨간(노란) 칠로 표시되고, 마우스를 올리면 이유가 보입니다. **직접 고치기**를 누르면 고칠 수 있습니다.
   - **시각자료 이미지**: 그림·사진·그래프·도표·지도는 원본 고해상도 이미지에서 자동으로 잘라 미리 보여 줍니다. 영역이 틀렸으면 **영역 고치기**로 상자를 끌어 바로잡습니다. 사이트에 올리는 것은 “넣기”를 누를 때입니다.
   - **OCR과 달라진 곳**: 빨간 줄은 지운 것, 초록은 새로 넣은 것입니다.
4. 결과가 맞으면 **넣고 임시저장** 또는 **넣고 저장 후 다음 쪽**을 누릅니다.

특수한 쪽: 장 표지는 제목 한 줄(목차 단계 표시), 사진만 있는 쪽은 시각자료 블록, 빈 쪽은 “빈 면”으로 씁니다. 원본에 쪽 번호가 없으면 앞쪽 번호로 추정해 넣고(“페이지번호 없음”은 체크하지 않음) 확인할 것에 띄웁니다.

### 자동 모드

**자동 모드 시작**을 누르면 쪽마다 교정 → 넣기 → 저장 → 다음 쪽을 반복합니다. 확인할 것(빨간 항목)이 있는 쪽, 남은 시간이 설정값보다 적을 때, 마지막 쪽에서는 항상 멈추고, 시각자료·특수한 쪽·쪽 번호 추정·규칙 경고에서 멈출지는 **상세 설정**에서 고릅니다. 표 그리기는 사람이 해야 합니다.

### 연습 페이지

배정이 없어도 시험해 볼 수 있습니다. 패널 아래쪽이나 **설정** 탭의 **연습 페이지 열기**를 누르면 새 탭에 마이픽 편집 화면을 흉내 낸 연습 화면이 열립니다. 예시 쪽(시 인용, 그림 쪽 2개, 장 표지, 사진 쪽)이 들어 있고, 아래 **내 원본 이미지로 시험하기**에서 내 쪽 이미지와 OCR 글자를 넣을 수 있습니다. 교정, 자동 모드, 쪽 넘김 간격, 시각자료 넣기까지 실제처럼 동작하지만 저장·그림 올리기·목차는 이 컴퓨터 안에서만 흉내 내고 사이트로는 아무것도 보내지 않습니다. Claude 호출은 실제로 하므로 비용이 듭니다. 예시 쪽 이미지는 개인 자료라 저장소에는 없고 배포 zip에만 들어 있습니다.

**설정** 탭: API 키, AI 모델(기본 Claude Opus 5.5).

## 비용

사용한 만큼 Anthropic API 요금이 나옵니다. 패널 아래에 쪽마다 대략적인 비용이 표시됩니다. Opus 5.5 기준으로 한 쪽에 대략 100~200원 정도로 예상하며, 글자 수와 그림에 따라 달라집니다.

## 개발자용

```
extension/
  manifest.json        Manifest V3
  background.js        아이콘 클릭 시 사이드 패널 열기
  sidepanel.*          화면과 작업 흐름 (확인 모드 / 자동 모드)
  lib/page.js          편집 화면(main world)에서 실행: 읽기, 이미지·목차 가져오기, 넣기, 저장
  lib/prompt.js        Claude 작업 지침(안내서 규칙 요약)과 응답 형식
  lib/claude.js        Messages API 호출
  lib/rules.js         결정적 규칙 검사기
  lib/diff.js          OCR 비교
  lib/convert.js       편집기 데이터(줄마다 <br>) 변환, 이미지 축소
  lib/visuals.js       시각자료 블록, 잘라내기, <figure> 넣기
  lib/fixes.js         2차 검증 수정 적용
tests/
  *.test.js            규칙 검사기·시각자료·수정 적용 테스트:  npm test
  e2e.mjs              모의 편집 화면 + 가짜 API로 전체 흐름 테스트:  npm run e2e (Playwright 필요)
```

편집 화면 연결: 편집기는 CKEditor 4 `CKEDITOR.instances.content`, 내용은 줄마다 `<br>`. 원본 이미지 `#book_img`, 쪽 번호 `#page_num`, 번호 없음 `#none_page`, 작업 쪽 `#curr_page`, 제작 Tip `.makeTip`, 남은 시간 `.time`. 시각자료는 사이트의 이미지 자르기 창과 같은 방식으로 `/module/book/cropbox_upload_proc.php`에 올리고 `<figure class="image">`로 넣습니다. 저장은 사이트의 `saveGo('temp')`, `saveGo('next')`만 호출하며 `saveGo('complete')`(최종 제출)는 호출하지 않습니다. 사이트는 내용에 `&lt;`, `&gt;`, `chrome-extension`, `<script>` 가 있으면 저장을 거부하므로 넣기 전에 검사합니다.
