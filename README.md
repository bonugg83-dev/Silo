# Silo · 마이픽 전자도서 교정 도우미 (크롬 확장 프로그램)

실로암시각장애인복지관 **마이픽 전자도서 제작** 편집 화면에서, 왼쪽 원본 이미지를 Claude가 직접 보고 오른쪽 OCR 텍스트를 「전자도서제작안내서」 규칙에 맞게 다시 작성해 주는 도우미입니다.

- 원본 이미지가 기준이고, OCR 텍스트는 비교용으로만 씁니다.
- 유니코드 부호(줄표 ―, 산괄호 〈 〉, 부등호 ＜ ＞, 빼기 −, 가운뎃점 ·, 한글 따옴표, ㎝ 등), 빈 줄, 괄호 짝, 띄어쓰기는 프로그램이 한 번 더 검사하고 고칩니다.
- 시각자료, 주석, 애매한 제목 단계, 쪽 번호처럼 사람이 봐야 하는 것은 “확인할 것”에 표시합니다.
- **“제출하기”(최종 제출)는 절대 누르지 않습니다.** 모든 쪽을 확인한 뒤 직접 눌러 주세요.

## 설치 (처음 한 번)

1. 이 저장소를 내려받습니다. GitHub 페이지에서 **Code → Download ZIP** 을 누르고 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions` 를 입력해 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고, 압축을 푼 폴더 안의 **`extension`** 폴더를 선택합니다.
5. 크롬 툴바의 퍼즐 모양 아이콘을 누르고 “Silo” 옆 핀을 눌러 고정합니다.

코드를 새로 내려받았을 때는 `chrome://extensions` 에서 이 확장 프로그램의 새로고침(↻) 버튼을 누르면 됩니다.

## 계정과 API 키

Silo는 **로그인해야 쓸 수 있어요.** 계정은 온라인(구글 Firebase, 무료 요금제)에 저장돼서 **어느 컴퓨터에서나 같은 아이디·비밀번호로 로그인**할 수 있어요. 가입하려면 관리자에게 받은 **가입 코드**가 필요해요.

1. [console.anthropic.com](https://console.anthropic.com) 에서 API 키를 발급받고 크레딧을 충전합니다. (교정자마다 Workspace를 따로 만들어 키를 받으면 콘솔에서도 사람별 지출 한도를 걸 수 있어요.)
2. 로그인 화면에서 **회원가입**을 눌러 아이디, 비밀번호, 가입 코드, API 키를 넣고 **가입하고 시작하기**를 누릅니다.
3. 다음부터는 어느 컴퓨터에서든 아이디와 비밀번호로 로그인합니다.
4. **설정(☰)** 의 **내 계정**: 키 바꾸기, 오늘·이번 달 쓴 비용, 이번 달 한도(넘으면 자동모드가 그 쪽까지만 하고 멈춤), 안 쓰면 자동 로그아웃(30분·1시간·4시간·브라우저를 닫을 때), 비밀번호 바꾸기, 로그아웃. 계정 지우기는 상세 설정 맨 아래에 있어요.

- 온라인에 저장되는 것: 계정, API 키(잠긴 채로), 설정, 비용 합계(여러 컴퓨터 합계). **책 진행은 컴퓨터마다 따로**예요.
- API 키는 계정 비밀번호로 암호화(PBKDF2 → AES-GCM)한 뒤에만 올라가요. 로그인 비밀번호도 해시로 바꿔 보내서, 서버나 관리자는 키를 풀 수 없어요. 로그인한 동안만 풀린 키가 브라우저 세션에 있고, 로그아웃하거나 브라우저를 닫으면 사라져요.
- 인터넷이 안 되면 그 컴퓨터에서 로그인했던 계정으로 들어가요. 그동안 쓴 비용은 다음에 인터넷이 될 때 올라가요. 비밀번호 바꾸기·계정 지우기는 인터넷이 될 때만 돼요.
- 비밀번호를 잊으면 찾을 수 없어요. 관리자에게 계정 삭제를 부탁한 뒤 같은 아이디로 다시 가입하고 API 키를 다시 넣어요. (관리자: Firebase 콘솔 → Authentication → 사용자에서 지움. 아이디가 아니라 내부 주소로 보이니, 사용자 UID를 Firestore `users` 문서의 name 칸으로 찾아요.)
- 교정이 도는 동안에는 시작할 때의 계정과 키로 끝까지 가고, 같은 계정으로 다른 창에서 동시에 교정할 수 없어요.
- 예전 버전(v0.10)에서 이 컴퓨터에만 만든 계정은 처음 로그인할 때 가입 코드를 한 번 넣으면 온라인으로 옮겨져요. v0.9 이하에서 저장해 둔 키는 첫 회원가입 때 고를 수 있어요.

## 사용법

1. 마이픽에서 평소처럼 편집 화면(팝업 창)을 엽니다.
2. **원래 크롬 창**의 툴바에서 도우미 아이콘을 눌러 사이드 패널을 엽니다. 패널이 편집 화면을 알아서 찾습니다.
3. 맨 위 버튼 한 줄: **교정하기**(이 쪽), **자동 모드**(끝까지 진행, 도는 중엔 **멈추기**), **편집기에 넣기**(저장은 사이트 버튼으로).
4. 작성 결과에서 빨간 칠은 꼭 확인할 곳, 노란 칠은 참고할 곳이고 마우스를 올리면 이유가 보입니다. 본문에 위치가 없는 것(쪽 번호 추정 등)은 쪽 번호 옆 점으로 표시됩니다. 그림은 `@@i` 자리에 작게 보이고, 누르면 영역을 고칠 수 있습니다.
5. 아래 **[OCR] [수정] [목차]** 버튼으로 OCR과 달라진 곳, 고친 내용, 이 책 목차를 펼칩니다.

### 자동 모드와 검수

자동 모드는 쪽마다 교정 → 넣기 → 저장 → 다음 쪽을 마지막 쪽까지 반복합니다(쪽마다 기본 60~90초 중 무작위 시간이 지나야 넘어감). 끝나면 **검수 N** 버튼과 목록이 나옵니다.

- **이 쪽 열기**: 편집 화면이 그 쪽으로 가고 패널에 내용이 뜹니다. 확인했으면 결과 아래 **확인함**을 누릅니다(고친 게 있으면 넣고 임시저장까지 함).
- **다른 쪽에 걸친 각주**: 앞쪽에 번호만 있고 설명이 다음 쪽에 있으면 짝을 기억해 두었다가 **반영**을 누르면 앞쪽 번호 자리로 옮기고 두 쪽을 다시 임시저장합니다.

### 연습 페이지

배정이 없어도 시험해 볼 수 있습니다. 패널 아래쪽이나 **설정** 탭의 **연습 페이지 열기**를 누르면 새 탭에 마이픽 편집 화면을 흉내 낸 연습 화면이 열립니다. 예시 쪽(시 인용, 그림 쪽 2개, 장 표지, 사진 쪽)이 들어 있고, 아래 **내 원본 이미지로 시험하기**에서 내 쪽 이미지와 OCR 글자를 넣을 수 있습니다. 교정, 자동 모드, 쪽 넘김 간격, 시각자료 넣기까지 실제처럼 동작하지만 저장·그림 올리기·목차는 이 컴퓨터 안에서만 흉내 내고 사이트로는 아무것도 보내지 않습니다. Claude 호출은 실제로 하므로 비용이 듭니다. 예시 쪽 이미지는 개인 자료라 저장소에는 없고 배포 zip에만 들어 있습니다.

## 설정

**설정** 탭: 내 계정(키·비용·한도·자동 로그아웃), AI 모델, **연습 페이지 열기**, **상세 설정**(2차 검증, 줄표 띄어쓰기, 시각자료 자동 넣기, 자동 모드 쪽 넘김 간격). 나머지(꼼꼼함 높음, 이미지 2000px, 목차 사용, 단위 기호)는 기본값으로 고정입니다.

## 비용

사용한 만큼 Anthropic API 요금이 나옵니다. 패널 아래에 쪽마다 대략적인 비용이 표시됩니다. Opus 5.5 기준으로 한 쪽에 대략 100~200원 정도로 예상하며, 글자 수와 그림에 따라 달라집니다.

## 개발자용

```
extension/
  manifest.json        Manifest V3
  background.js        아이콘 클릭 시 사이드 패널 열기
  sidepanel.*          화면과 작업 흐름 (확인 모드 / 자동 모드)
  lib/page.js          편집 화면(main world)에서 실행: 읽기, 이미지·목차 가져오기, 넣기, 저장
  lib/prompt.js        Claude 작업 지침(안내서 규칙 요약)과 응답 형식
  lib/claude.js        Messages API 호출
  lib/profiles.js      계정: 키 암호화, 계정별 저장 키, 자동 로그아웃·월 한도
  lib/rules.js         결정적 규칙 검사기
  lib/diff.js          OCR 비교
  lib/convert.js       편집기 데이터(줄마다 <br>) 변환, 이미지 축소
  lib/visuals.js       시각자료 블록, 잘라내기, <figure> 넣기
  lib/fixes.js         2차 검증 수정 적용
  lib/footnotes.js     다른 쪽에 걸친 각주 잇기
  practice/            연습 페이지
tests/
  *.test.js            규칙 검사기·시각자료·수정 적용 테스트:  npm test
  e2e.mjs              모의 편집 화면 + 가짜 API로 전체 흐름 테스트:  npm run e2e (Playwright 필요)
```

편집 화면 연결: 편집기는 CKEditor 4 `CKEDITOR.instances.content`, 내용은 줄마다 `<br>`. 원본 이미지 `#book_img`, 쪽 번호 `#page_num`, 번호 없음 `#none_page`, 작업 쪽 `#curr_page`, 제작 Tip `.makeTip`, 남은 시간 `.time`. 시각자료는 사이트의 이미지 자르기 창과 같은 방식으로 `/module/book/cropbox_upload_proc.php`에 올리고 `<figure class="image">`로 넣습니다. 저장은 사이트의 `saveGo('temp')`, `saveGo('next')`만 호출하며 `saveGo('complete')`(최종 제출)는 호출하지 않습니다. 사이트는 내용에 `&lt;`, `&gt;`, `chrome-extension`, `<script>` 가 있으면 저장을 거부하므로 넣기 전에 검사합니다.

## 로고와 시작 모션

- 이름 **Silo**는 실로암(히브리어 실로아흐, ‘보냄을 받은 것, 보내진 물’)에서 왔습니다.
- 로고 글꼴은 Libre Caslon Text Bold(SIL Open Font License, `extension/fonts/OFL.txt`)이고, i의 점만 파란색입니다.
- 하루 처음 패널을 열 때 시작 모션(물방울 → 물결 → 로고가 왼쪽 위로)이 약 3초 나옵니다. 화면을 누르면 건너뜁니다. 움직임 줄이기 설정이면 나오지 않습니다.
